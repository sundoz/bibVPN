# bibVPN

Свой обход блокировок: серверы на **Xray (VLESS + Reality)**, которыми управляет одна
CLI-утилита. Клиенты берём готовые (Hiddify, v2rayNG, v2rayN, Happ, v2RayTun, Streisand…),
поэтому поддерживаются все платформы: Android, iOS, Windows, macOS, Linux.

## Как это работает

```
 телефон/ноутбук ──TLS 1.3 на :443──▶ ваш VPS за границей ──▶ интернет
 (готовый клиент)   для ТСПУ выглядит как     (Xray, Reality)
                    заход на www.<сайт>.com
```

* **Reality**: сервер притворяется настоящим зарубежным сайтом (`--sni`). У того, кто
  подключится без ключа (в том числе у активного зондирования ТСПУ), откроется настоящий
  сайт с настоящим сертификатом. Свой домен и сертификат не нужны.
* На одном порту 443 работают два транспорта, клиент может переключаться между ними:
  * **Vision** (`bib-<node>-vision`): основной и самый быстрый;
  * **XHTTP** (`bib-<node>-xhttp`): запасной, трафик идёт как HTTP/2-запросы. Помогает,
    когда долгие соединения режут или замедляют.
* **Хаб** (необязательный небольшой сервер в РФ) раздаёт пользователям **подписки**
  (приложения сами получают изменения), каждые 5 минут проверяет все серверы изнутри
  РФ и пишет в Telegram, если что-то сломалось.
* Все секреты хранятся в одном файле `state/bibvpn.yml`. Конфиги серверов, инвентарь
  Ansible и ссылки для клиентов генерируются из него.

## Быстрый старт

### 0. Сервер
Нужен VPS за пределами РФ на **Ubuntu 22.04+/Debian 12+**, 1 vCPU / 1 ГБ RAM.
Как выбрать хостинг и SNI: [docs/HOSTING.md](docs/HOSTING.md).

Настройте вход по SSH-ключу (при деплое вход по паролю отключается; если ключа нет,
плейбук остановится, чтобы вы не потеряли доступ):
```bash
ssh-copy-id root@<IP>
```

### 1. Установка на свой компьютер
```bash
make dev                    # .venv с bibvpn, Ansible и тестами
source .venv/bin/activate
```

### 2. Сервер и пользователи
```bash
bibvpn init                                     # создаёт state/bibvpn.yml
bibvpn check-target www.some-site.fi            # подходит ли сайт для маскировки
bibvpn node add fi1 <IP> --sni www.some-site.fi
bibvpn user add me
bibvpn user add mom --note "телефон мамы"
```

### 3. Деплой
```bash
bibvpn deploy               # подготовка и защита сервера, установка Xray, проверка
bibvpn deploy --check       # сухой прогон с diff
bibvpn deploy --limit fi1 -v  # незнакомые опции передаются в ansible-playbook
```
Деплой можно запускать сколько угодно раз: если ничего не менялось, он ничего и не
меняет. Новый конфиг сначала проверяется бинарником Xray и только потом применяется.

### 3½. Хаб: подписки и мониторинг (рекомендуется)
```bash
bibvpn hub set <IP сервера в РФ>              # домен по умолчанию: <ip>.sslip.io
bibvpn monitor set --telegram-token <от @BotFather> --telegram-chat-id <ваш id>
bibvpn deploy
bibvpn monitor test                           # тестовое сообщение в Telegram
bibvpn status                                 # результаты проверок
bibvpn sub me --qr                            # ссылка подписки для приложения
```
Подробно: [GUIDE.md, раздел 9](docs/GUIDE.md#9-хаб-подписки-и-мониторинг).

### 4. Подключение
```bash
bibvpn links me --qr        # ссылки vless:// и QR-коды
```
Отсканируйте QR или вставьте ссылку в клиент. Добавьте обе ссылки: Vision как основную,
XHTTP как запасную.

| Платформа | Клиенты |
|---|---|
| Android | v2rayNG, Hiddify, Happ, v2RayTun |
| iOS / macOS | Happ, v2RayTun, Streisand, Hiddify |
| Windows / Linux | v2rayN, Hiddify |

Ссылки Vision поддерживают все клиенты. XHTTP пока понимают только клиенты на ядре Xray
(v2rayNG, v2rayN, Happ, v2RayTun, Streisand). В клиенте включите маршрутизацию
«Россия напрямую» (geoip/geosite `ru`): российские сайты не должны идти через VPN.

## Ежедневная работа

| Задача | Команда |
|---|---|
| Проверить, всё ли работает | `bibvpn status` |
| Утекла ссылка подписки | `bibvpn user rotate-sub NAME`, затем `deploy` |
| Отключить или вернуть пользователя | `bibvpn user disable NAME` / `enable`, затем `deploy` |
| Удалить пользователя | `bibvpn user rm NAME`, затем `deploy` |
| Сервер заблокировали, сменить SNI | `bibvpn node set fi1 --sni ...`, затем `deploy` |
| Сменить ключи сервера | `bibvpn node set fi1 --rotate-keys`, затем `deploy` (ссылки нужно раздать заново) |
| Обновить Xray | поменять `xray_version`/`xray_sha256` в `ansible/roles/xray_bin/defaults/main.yml`, затем `deploy` |

**Сделайте бэкап `state/bibvpn.yml`.** Это единственное место, где хранятся ключи.
Файл есть в `.gitignore`, в репозиторий он не попадает.

## Разработка

```bash
make test          # 138 тестов; если xray есть в PATH, он же проверяет конфиги
make lint          # ansible-lint
make integration   # полный деплой сервера и хаба в одноразовые контейнеры
                   # Ubuntu+systemd: подключение реальным клиентом, проверки
                   # безопасности, подписки по HTTPS, сценарий «сервер упал»
                   # с уведомлением, отзыв доступа
```
